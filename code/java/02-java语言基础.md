Java的8种基本数据类型（8 Basic Data Types） #card

- **整型（4种）**：byte（8位）、short（16位）、int（32位）、long（64位）。（注：Java无无符号整型）
- **浮点型（2种）**：float（32位）、double（64位）。
- **字符型（1种）**：char（16位）。采用 Unicode 编码，占2个字节，可存放一个中文字符。
- **布尔型（1种）**：boolean。取值只能是 true 或 false。

Scanner 标准输入机制（Scanner Standard Input） #card

使用 Scanner 从键盘读取输入数据的三个核心步骤：
- **导包**：程序开头使用 `import java.util.*;` 或 `import java.util.Scanner;`。
- **创建对象**：实例化扫描器 `Scanner input = new Scanner(System.in);`。
- **调用方法读取**：根据数据类型调用对应方法，例如 `nextInt()`、`nextDouble()`、`nextLine()` 等。
