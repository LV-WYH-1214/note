`String` 类的核心操作方法（Core String Methods） #card

- `length()`：返回字符串的长度。
- `charAt(int index)`：返回指定下标处的字符（注意下标范围是 $0$ 到 $n-1$）。
- `trim()`：返回去掉两边空白字符的新字符串。
- `equals(s1)`：判断两个字符串内容是否相等，返回布尔值。
- `compareTo(s1)`：比较两个字符串，返回大于 0、等于 0 或小于 0 的整数。
- `indexOf(ch)`：返回指定字符首次出现的下标，若不存在则返回 -1。

字符串与基本数据类型的相互转换（String Conversions） #card

- **字符串转数字**：必须使用封装类的解析方法，如 `Integer.parseInt(String s)` 和 `Double.parseDouble(String s)`。
- **数字转字符串**：最简单的常考做法是使用 `+` 连接空串，例如 `"" + i`。
- **字符串转布尔型**：使用 `Boolean.parseBoolean(String s)`（转换为字符串后内容只能是 "true" 或 "false"）。
