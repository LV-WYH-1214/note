对象（Object） #card

系统中用来描述客观事物的一个实体。
- 构成：属性（描述静态特征） + 行为/功能（描述动态特征）。
- 核心等式：对象 = 属性 + 行为。

面向对象的三大特性 #card

面向对象编程的基础：
- 封装（Encapsulation）：将属性和行为结合为独立单元，隐蔽内部细节，仅暴露有限接口以保证数据安全。
- 继承（Inheritance）：描述类间的“父-子关系”。子类包含父类成员并可扩展新成员，实现代码重用。
- 多态（Polymorphism）：父类引用指向子类对象，调用方法时根据引用对象的实际类型决定具体行为。
