Java参数传递机制（Parameter Passing Mechanism） #card

- **传值机制**：Java调用方法时，严格通过**传值**将实参的值拷贝给形参。
- **核心准则（易错点）**：形参在方法内部的任何改变（如自增运算、重新赋值），**绝对不会影响**外部的实参。

方法重载（Method Overloading） #card

- **定义**：同一个类中允许存在多个方法名相同的方法。
- **构成条件（核心）**：必须具有**不同的参数列表**（包括参数的个数不同、类型不同、顺序不同）。
- **高频陷阱**：仅仅**返回类型或修饰符不同绝对不能**作为重载的依据（名称和参数列表完全相同但返回值不同会直接报错）。
- **匹配与二义性**：调用时编译器遵循“最精确匹配原则”；若存在两个及以上的方法都能匹配且无法判断“最精确”，则会引发二义性编译错误。
