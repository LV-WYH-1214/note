
树（Tree）的定义 #card

树是 $n$ ($n \ge 0$) 个结点的有限集。当 $n = 0$ 时称为空树。在任意一棵非空树中必须满足：有且仅有一个特定的称为根的结点；当 $n > 1$ 时，其余结点可分为 $m$ ($m > 0$) 个互不相交的有限集，其中每一个集合本身又是一棵树，称为根的子树。

结点的度（Degree of a Node）是什么？ :: 树中一个结点的孩子个数。

树的度（Degree of a Tree）是什么？ :: 树中所有结点的度的最大值。

分支结点与叶结点分别指什么？ :: 度大于0的结点称为分支结点（非终端结点）；度为0的结点称为叶结点（终端结点）。

结点的深度（Depth）与高度（Height）的区别是什么？ :: 结点的深度是从根结点开始自顶向下逐层累加的；结点的高度是从叶结点开始自底向上逐层累加的。树的高度是树中结点的最大层数。

路径长度（Path Length）是什么？ :: 两个结点之间的路径是由从一个结点到另一个结点所经过的结点序列构成的，路径长度则是该路径上边的数目。

树的结点数与结点的度数之间有什么数量关系？ :: 树的结点总数 $n$ 等于所有结点的度数之和加1，即 $n = \sum \text{度数} + 1 = \text{边数} + 1$。<br><br>**（注：以下推理过程仅供理解，不用背诵）**<br>结点与其每个孩子都有唯一的边相连，因此树中所有结点的度数之和等于总边数；又因为除根结点外，每个结点均有唯一的双亲（即每条边对应一个下层结点），所以结点总数 $n$ 等于边数加1。

度为 $m$ 的树中，第 $i$ 层至多有多少个结点（$i \ge 1$）？ :: $m^{i-1}$ 个结点。

高度为 $h$ 的 $m$ 叉树至多有多少个结点？ :: $\frac{m^h - 1}{m - 1}$ 个结点。<br><br>**（注：以下推理过程仅供理解，不用背诵）**<br>当各层结点数达到最大时，第 $i$ 层有 $m^{i-1}$ 个结点。树中结点总数为等比数列求和：$1 + m + m^2 + \dots + m^{h-1} = \frac{m^h - 1}{m - 1}$。

具有 $n$ 个结点的度为 $m$ 的树的最小高度 $h$ 是多少？ :: $h = \lceil \log_m(n(m-1)+1) \rceil$。<br><br>**（注：以下推理过程仅供理解，不用背诵）**<br>要使高度最小，树应尽可能饱满。前 $h-1$ 层最多有 $\frac{m^{h-1} - 1}{m - 1}$ 个结点，前 $h$ 层最多有 $\frac{m^h - 1}{m - 1}$ 个结点。因此有 $\frac{m^{h-1} - 1}{m - 1} < n \le \frac{m^h - 1}{m - 1}$，解得 $h-1 < \log_m(n(m-1)+1) \le h$。因为 $h$ 为整数，所以 $h = \lceil \log_m(n(m-1)+1) \rceil$。

二叉树（Binary Tree） #card

一种特殊的树形结构，其核心特征为：每个结点至多只有两棵子树（不存在度大于2的结点），且子树有明确的左右之分，次序不能颠倒。

二叉树与度为2的有序树有什么本质区别？ #card

- 度为2的树至少包含3个结点，而二叉树可以为空。
- 度为2的有序树中如果某结点只有一个孩子，无需区分左右次序；二叉树中无论结点是否拥有两个孩子，其子树的左右位置都是确定的且不可省略的。

满二叉树（Full Binary Tree） #card

一棵高度为 $h$ 且包含 $2^h - 1$ 个结点的二叉树。其特点是：
- 每一层都含有该层所能容纳的最大结点数。
- 所有叶结点均位于最下一层。
- 除叶结点外，其余每个结点的度均为2。

完全二叉树（Complete Binary Tree） #card

高度为 $h$、包含 $n$ 个结点的二叉树，当且仅当其每个结点都与高度为 $h$ 的满二叉树中编号为 $1 \sim n$ 的结点一一对应时，称为完全二叉树。

二叉排序树（Binary Search Tree） #card

一棵二叉树，具有以下性质：
- 左子树上所有结点的关键字均小于根结点的关键字。
- 右子树上所有结点的关键字均大于根结点的关键字。
- 左子树和右子树本身也各是一棵二叉排序树。

平衡二叉树（Balanced Binary Tree）的前提条件是什么？ :: 树中任意一个结点的左子树和右子树的高度之差的绝对值不超过1。

正则二叉树（Regular Binary Tree）的特征是什么？ :: 树中每个分支结点均有2个孩子，即树中仅有度为0或2的结点。

非空二叉树中度为0的叶结点数（$n_0$）与度为2的结点数（$n_2$）的关系式是什么？ :: $n_0 = n_2 + 1$。<br><br>**（注：以下推理过程仅供理解，不用背诵）**<br>设度为0、1、2的结点数分别为 $n_0, n_1, n_2$，则结点总数 $n = n_0 + n_1 + n_2$。除根结点外其余结点都有一个分支进入，设总分支数为 $B$，则 $n = B + 1$。这些分支均由度为1或2的结点射出，因此 $B = n_1 + 2n_2$。综合可得 $n_0 + n_1 + n_2 = n_1 + 2n_2 + 1$，化简即得 $n_0 = n_2 + 1$。

非空二叉树的第 $k$ 层至多有多少个结点（$k \ge 1$）？ :: $2^{k-1}$ 个结点。

高度为 $h$ 的二叉树至多有多少个结点（$h \ge 1$）？ :: $2^h - 1$ 个结点。

具有 $n$ 个（$n > 0$）结点的完全二叉树的高度 $h$ 公式是什么？ :: $h = \lceil \log_2(n+1) \rceil$ 或 $h = \lfloor \log_2 n \rfloor + 1$。<br><br>**（注：以下推理过程仅供理解，不用背诵）**<br>根据满二叉树性质，高度为 $h$ 的完全二叉树包含的结点数满足：$2^{h-1} - 1 < n \le 2^h - 1$。对不等式各边加1并取以2为底的对数，得到 $h-1 < \log_2(n+1) \le h$，由于 $h$ 为整数，所以向上取整得 $h = \lceil \log_2(n+1) \rceil$。（第二种公式同理可由 $2^{h-1} \le n < 2^h$ 推导得出）。

完全二叉树（自上而下、自左向右编号为 $1 \sim n$）中，最后一个分支结点的编号是多少？ :: $\lfloor n/2 \rfloor$。

完全二叉树中，若结点 $i$ 有左孩子，其左、右孩子的编号分别是什么？ :: 左孩子编号为 $2i$，右孩子编号为 $2i + 1$。

完全二叉树中，结点 $i$（$i > 1$）的双亲结点的编号是多少？ :: $\lfloor i/2 \rfloor$。

完全二叉树中，结点 $i$ 所在的层次（深度）是多少？ :: $\lfloor \log_2 i \rfloor + 1$。
