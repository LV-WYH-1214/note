#flashcards/数据结构

**满二叉树** / 完美二叉树（Perfect Binary Tree） #card

- 定义：一棵深度为 $k$ 且有 $2^k-1$ 个结点的树称为满二叉树。
- 每一层的节点数都是最大节点数。
- 所有分支结点都存在左右子树，且所有叶结点都在同一层上。

深度为 $k$ 的二叉树最大结点数是多少？ :: $2^k - 1$<br><br>**附：证明过程（无需背诵，理解即可）**<br>由性质1可知每一层最大结点数为 $2^{i-1}$，因此有：深度为 $k$ 的二叉树最大结点数 $= \sum_{i=1}^{k} 2^{i-1} = 2^k - 1$

对于二叉树 $T$，设 $n_0$ 为叶结点个数，$n_2$ 为度为2的结点个数，它们之间的恒等关系式是什么？ :: $n_0 = n_2 + 1$<br><br>**附：证明过程（无需背诵，理解即可）**<br>1. 结点总数 $n = n_0 + n_1 + n_2$<br>2. 边总数（除根节点外每个节点都有一条入边） $n - 1 = n_1 + 2n_2$<br>将两式相减即得：$n_0 = n_2 + 1$
