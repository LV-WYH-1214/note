#flashcards/数据结构

栈（Stack） #card

- 定义：限定仅在表尾（栈顶）进行插入或删除操作的线性表，属于操作受限的线性表。
- 核心特性：后进先出（LIFO, Last In First Out）。
- 存储约定：顺序栈通常设 `base` 指针指示栈底，`top` 指针指示栈顶；链栈通常以链表头部作为栈顶。

链栈的插入和删除操作通常在链表的哪一端进行？ :: 只能在链表的栈顶进行（通常以链表头部作为栈顶最为方便，不需要附加头节点）。

栈的经典应用场景（Applications of Stack） #card

- 数制转换（如十进制转八进制）。
- 括号匹配检验。
- 表达式求值（如算符优先法，包含中缀表达式转后缀表达式及后缀求值）。
- 回溯算法及函数调用与递归实现。

系统在执行递归函数时，设立的“递归工作栈”主要用于保存什么内容？ :: 保存每一层调用过程中的所有实参、局部变量和上一层的返回地址。

队列（Queue） #card

- 定义：只允许在表的一端（队尾）插入，在另一端（队头）删除的线性表。
- 核心特性：先进先出（FIFO, First In First Out）。
- 应用场景：操作系统中的作业排队（如打印机缓冲区，解决主机与外设速度不匹配引起的资源竞争问题）、舞伴问题。
^1776413646054

假溢出（False Overflow） #card

- 定义：一般的顺序队列在经过不断的入队出队后，即使实际数组空间未满，队尾指针（`rear`）也可能达到数组末尾而无法继续插入的现象。
- 解决办法：采用循环队列，通过“模（$\%$）”运算将顺序队列的头尾指针在到达最大下标后折返回 $0$，变为首尾相接的环状空间。
^1776413646055

循环队列的队空条件和队满条件分别是什么（采用少用一个元素空间的策略以作区分）？ :: 队空条件：$front == rear$；队满条件：$(rear + 1) \mathbin{\%} MAXQSIZE == front$。

栈和队列在逻辑结构和操作特性上的共性和差异分别是什么？ :: 共性：都属于操作受限的线性表，数据元素之间存在一对一的逻辑关系。差异：栈只能在表的一端（栈顶）进行插入和删除；队列在表的一端（队尾）插入，另一端（队头）删除。
