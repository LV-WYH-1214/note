抽象数据类型（ADT）与面向对象思想的对应 #card
主要体现在以下两个方面：
- 信息隐藏：抽象数据类型独立于具体实现，将数据和操作封装在一起，使用户程序只能通过定义的某些操作访问数据。
- 两层抽象：相当于在概念层（抽象层）和实现层上描述问题。

抽象数据类型（ADT）实现的完整结构 #card
数据结构从理论到代码通常包含三个组成部分（如复数实现范例）：
- 定义部分：使用数学符号定义数据对象和数据关系，并声明基本操作的初始条件和操作结果。
- 表示部分：使用 typedef struct 定义具体的存储结构。
- 实现部分：使用类C语言编写各个基本操作的底层实现代码。
