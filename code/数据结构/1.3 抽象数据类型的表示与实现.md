抽象数据类型 (ADT) 的核心思想是什么？ #card
- **核心概念**：抽象数据类型 (Abstract Data Type, ADT)。
- **定义**：由用户定义的、表示应用问题的**数学模型**，以及定义在这个模型上的**一组操作**的总称。
- **核心思想**：**封装**与**信息隐藏**。将数据和操作封装在一起，使用者只需知道“做什么”，而无需知道“怎么做”及内部数据表示。
- **三层抽象**：
    1. **概念层 (ADT)**：描述问题“是什么”。
    2. **实现层 (类/结构体+函数)**：描述“如何做”。
    3. **应用层 (主程序)**：使用对象解决实际问题。

抽象数据类型 (ADT) 的标准定义格式是什么？ #card
 
标准格式如下：
```
ADT 抽象数据类型名 {
    数据对象: 〈数据对象的定义〉
    数据关系: 〈数据关系的定义〉
    基本操作: 〈基本操作的定义〉
} ADT 抽象数据类型名
```
其中，**基本操作的定义格式**为：
```
基本操作名(参数表)
    初始条件: 〈描述〉
    操作结果: 〈描述〉
```
**参数类型**：
- **赋值参数**：仅提供输入值。
- **引用参数 (`&`)**：既提供输入值，也返回操作结果。

在数据结构中，用于描述算法的“类C语言”有哪些关键约定？ #card**  


**牌后面**  
关键约定包括：

1. **数据元素类型**：约定为 `ElemType`，由用户在使用时具体定义。
2. **引用参数**：使用 `&` 表示，实现类似C++的引用调用，形参改变直接影响实参。
3. **动态分配**：使用 `new` 和 `delete` 替代C中的`malloc`和`free`。
4. **输入输出**：使用C++流 `cin` 和 `cout` 进行描述。
5. **简化语句**：扩展了赋值（如`i++`）、结束（`return`）、选择（`if-else`）等语句的写法，增强描述性。

实现一个抽象数据类型 (ADT) 通常分为哪三个步骤？以“复数”为例说明。 #card**  


**牌后面**  
实现ADT通常分为三个步骤：

1. **定义 (ADT)**：从逻辑上描述数学模型和操作。例如，定义复数由实部和虚部构成，并定义加法、减法等操作。
2. **表示 (存储结构)**：用编程语言定义数据的存储结构。例如，用C语言的`typedef`定义结构体`Complex { float real, imag; }`。
3. 3. **实现 (基本操作)**：用函数实现每个基本操作。例如，实现`Create(&C, r, i)`、`Add(C1, C2)`等函数。
4. - **最终效果**：实现后，用户可以像使用内置类型（如`int`）一样，使用`Complex`类型来声明变量和进行运算。
