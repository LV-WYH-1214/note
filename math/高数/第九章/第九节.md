二元函数的泰勒公式展开式 #card

设函数 $z=f(x,y)$ 在点 $(x_0, y_0)$ 邻域内具有 $(n+1)$ 阶连续偏导数：
$f(x_0+h, y_0+k) = f(x_0, y_0) + (h\frac{\partial}{\partial x} + k\frac{\partial}{\partial y})f(x_0, y_0) + \frac{1}{2!}(h\frac{\partial}{\partial x} + k\frac{\partial}{\partial y})^2 f(x_0, y_0) + \dots + \frac{1}{n!}(h\frac{\partial}{\partial x} + k\frac{\partial}{\partial y})^n f(x_0, y_0) + R_n$

二元函数泰勒公式的两种常见余项 $R_n$ #card

* **拉格朗日余项**（用于确切误差估计）：$R_n = \frac{1}{(n+1)!}(h\frac{\partial}{\partial x} + k\frac{\partial}{\partial y})^{n+1} f(x_0+\theta h, y_0+\theta k)$，其中 $0 < \theta < 1$。
* **皮亚诺余项**（用于局部近似计算）：$R_n = o(\rho^n)$，其中 $\rho = \sqrt{h^2 + k^2} \to 0$。
