梯度（Gradient）与 Nabla 算子 #card

* **梯度的定义**：由函数在该点的各个偏导数作为坐标分量构成的向量。三维情形记作 $\text{grad } f(x,y,z) = \nabla f = f_x \mathbf{i} + f_y \mathbf{j} + f_z \mathbf{k}$。
* **Nabla 算子（$\nabla$）**：即向量微分算子，$\nabla = \frac{\partial}{\partial x}\mathbf{i} + \frac{\partial}{\partial y}\mathbf{j} + \frac{\partial}{\partial z}\mathbf{k}$。

方向导数与梯度的点积关系式是什么？ :: $\frac{\partial f}{\partial l} = \text{grad } f \cdot \mathbf{e}_l = |\text{grad } f| \cos\theta$（其中 $\theta$ 是梯度方向与指定方向 $l$ 的夹角）。
^1776662172846

方向导数的极值与梯度的关系（三大必背结论） #card

* **最大值（同向）**：沿**梯度方向**（$\theta = 0$）方向导数最大，最大值为 $|\text{grad } f|$。（函数值增加最快的方向）
* **最小值（反向）**：沿**负梯度方向**（$\theta = \pi$）方向导数最小，最小值为 $-|\text{grad } f|$。（函数值减少最快的方向）
* **零值（垂直）**：沿**与梯度垂直的方向**（$\theta = \frac{\pi}{2}$），方向导数为 0。

多元函数的梯度的几何意义是什么？ :: 二元函数的梯度是等值线 $f(x,y)=c$ 在该点处的法向量；三元函数的梯度是等值面 $f(x,y,z)=c$ 的法向量。

求解方向导数的标准解题三步曲 #card

1. 求各个偏导数，写出梯度向量 $\text{grad } f$；
2. 提取题目给定的方向向量，并将其**单位化**得到 $\mathbf{e}_l$；
3. 将梯度向量与单位方向向量求**点积**（对应坐标相乘再相加），即得方向导数。
