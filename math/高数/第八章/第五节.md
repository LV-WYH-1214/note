球面标准方程与一般方程特征 #card
- 标准方程：设球心在点 $M_0(x_0, y_0, z_0)$，半径为 $R$ 的球面方程为：$(x-x_0)^2 + (y-y_0)^2 + (z-z_0)^2 = R^2$。特别地，球心在原点时为 $x^2 + y^2 + z^2 = R^2$。
- 一般方程特征：形如 $Ax^2 + Ay^2 + Az^2 + Dx + Ey + Fz + G = 0$，只要 $x^2, y^2, z^2$ 的系数相同且无交叉乘积项，配方后图形即为球面（或点、虚轨迹）。

旋转曲面的求法（替换规律） #card
- 绕 $z$ 轴旋转：将 $yOz$ 面上的曲线 $f(y, z) = 0$ 中的 $y$ 替换为 $\pm\sqrt{x^2+y^2}$，得 $f(\pm\sqrt{x^2+y^2}, z) = 0$。
- 绕 $y$ 轴旋转：将方程中的 $z$ 替换为 $\pm\sqrt{x^2+z^2}$，得 $f(y, \pm\sqrt{x^2+z^2}) = 0$。
- 口诀记忆：绕哪个轴旋转，哪个变量就保留不变，另一个变量替换为“正负根号下另外两个变量的平方和”。

柱面方程的特征（空间直角坐标系） #card
- 缺 $z$ 变量：方程 $F(x, y) = 0$ 表示母线平行于 $z$ 轴的柱面。
- 缺 $x$ 变量：方程 $G(y, z) = 0$ 表示母线平行于 $x$ 轴的柱面。
- 缺 $y$ 变量：方程 $H(x, z) = 0$ 表示母线平行于 $y$ 轴的柱面。

常见二次曲面：椭球面与椭圆锥面 #card
- 椭球面：$\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1$ （所有变量平方项相加等于1）。
- 椭圆锥面：$\frac{x^2}{a^2} + \frac{y^2}{b^2} = z^2$。

常见二次曲面：单叶与双叶双曲面 #card
- 单叶双曲面：$\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$ （含有一个负号）。
- 双叶双曲面：$\frac{x^2}{a^2} - \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$ （含有两个负号）。

常见二次曲面：椭圆与双曲抛物面 #card
- 椭圆抛物面：$\frac{x^2}{a^2} + \frac{y^2}{b^2} = z$ （一次项 $z$ 等于另外两个变量的平方和，像个碗）。
- 双曲抛物面（马鞍面）：$\frac{x^2}{a^2} - \frac{y^2}{b^2} = z$ （一次项 $z$ 等于另外两个变量的平方差，像马鞍）。

常见二次曲面：三种二次柱面 #card
- 椭圆柱面：$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$。
- 双曲柱面：$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$。
- 抛物柱面：$x^2 = ay$ 或 $y^2 = 2x$ 等。
